# Project Synopsis

## Title
Nova AI Interview Simulator

## Objective
The objective of this project is to create a professional interview preparation platform that helps students practice technical interviews in a structured, realistic, and self-evaluative manner.

## Problem Statement
Many students struggle with interview preparation because they do not have access to consistent mock interview practice, structured question banks, or immediate feedback on answer quality. This project addresses that gap by simulating a recruiter-style interview environment.

## Proposed Solution
The system provides a secure login-based mock interview platform where users can:

- practice with a large interview-preparation question library
- attend voice-guided AI mock interviews
- receive automated feedback and scores
- review previous interview attempts
- export interview performance reports

## Core Modules

- Authentication and remembered login
- Practice library with 500 interview-preparation questions
- Voice-first interview workflow
- AI and rule-based answer evaluation
- History tracking and report export
- Admin analytics dashboard

## Technology Used

- Python
- Streamlit
- SQLite
- OpenAI SDK
- SpeechRecognition
- OpenCV
- ReportLab

## Outcome
The project provides an end-to-end interview preparation environment with both practice and simulated interview modes, making it useful as a final year project, a portfolio project, and a practical student tool.
